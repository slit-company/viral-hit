# Optional media batch inspector

This independently installed provider measures project image, video and audio files with FFprobe. It supports a single picture, sound, multiple videos or mixed sources. It is a technical inventory, not a semantic AI model or a quality benchmark.

Copy this folder into `VIRAL_HIT_PROVIDERS_DIR`, set `VIRAL_HIT_FFPROBE` to the existing FFprobe executable and restart. No dependency, daemon or model download is added by default. Choose **Media batch review** in Canvas Analysis, open **Analysis sources**, select media already placed on the Canvas, close the dialog and choose **Analyze**. Studio Analysis offers the same model with project-library selection and upload-once source files. The same `analysisInputs` contract is exposed to HTTP/MCP clients.

The model permits up to eight images, four videos and four audio files, with at least one source. The common project reader enforces ownership, hashes, 64 MiB/file and 256 MiB total/read limits. The processor reads and probes one file at a time, deletes each temporary file, bounds probe output to 1 MiB and each child to 20 seconds, and bounds the whole batch to 120 seconds. Unsupported formats or streams fail explicitly. It never accesses a network URL.

Text lists measured dimensions, codecs, duration where present, audio metadata and original checksums. Order is image, video, audio; order within each group matches the submitted references. It also returns a version 2 structured report with explicit per-kind source indices: still images have no timeline, while video/audio observations cover their own measured duration. Unknown or out-of-range durations (below 0.01 or above 3600 seconds) remain in text with a disclosure and are omitted from structured observations. No creative proposal is invented. In Storyboards, review the report and prepare selected observations as an unsaved editable plan; adding audio as a reference does not automatically add soundtrack. See [the versioned report contract](../../../docs/STRUCTURED-ANALYSIS.md).
