# 한국어 UI 작성 규칙

Viral Hit의 한국어 화면은 차분한 해요체를 쓴다. 메뉴와 버튼은 짧은 명사·동작으로, 안내와 오류는 문장으로 쓴다. 친근하게 쓰되 애교, 유행어, 성과를 약속하는 표현은 넣지 않는다.

## 뜻과 동작

- 번역 전에 실제 동작을 확인한다. 설치, 실행, 저장, 게시를 서로 바꾸어 쓰지 않는다.
- 가능성, 조건, 비용, 삭제 범위, 되돌릴 수 있는지는 원문대로 남긴다. 모르는 오류 원인이나 완료 시점을 지어내지 않는다.
- 완료 알림은 결과를 바로 말한다. “성공적으로 저장되었습니다” 대신 “저장했어요”를 쓴다.
- 오류에는 확인된 상황을 적고 가능한 다음 행동을 안내한다. 실패를 숨기거나 무조건 재실행을 권하지 않는다.
- 빈 화면은 처음 사용한 상태와 검색 결과가 없는 상태를 구분한다.
- 버튼은 “확인”을 반복하지 않고 “설치하기”, “변경 사항 검토”, “연결 해제”처럼 결과를 드러낸다.
- 사용자 이름이나 제목 뒤의 조사는 고정하지 않는다. “‘{name}’ 항목을 삭제할까요?”처럼 어떤 값에도 자연스러운 문장으로 쓴다.
- API 이름, 모델명, ID, URL, 경로, 명령어, JSON 키, 단위와 수치는 보존한다. 사용자가 쓴 콘텐츠나 외부 패키지의 원문을 자동 번역하지 않는다.

## 구현과 확인

한국어는 `ko` 로캘로 제공한다. 영어 기본 주소와 기존 언어 선택은 유지하고, `/ko` 주소 및 한국어 브라우저 설정으로 진입할 수 있게 한다. 번역은 메시지 파일에 두며 UI 문구와 저장 데이터·API 계약을 분리한다. 자리표시자, 키 누락, 명시적 언어 주소, 언어 전환 후 이동을 검사한다. 데스크톱 1440×960과 모바일 390×844에서 실제 화면의 줄바꿈, 잘림, 버튼 길이를 확인한다.

## 현재 통합 상태 — 2026-10-30

한국어 번역 브랜치의 문구를 현재 제작 화면에 통합했다. 새 작업 분류·모델 선택·제작 안내·소스 선택·오디오·분석 패널도 메시지 파일을 사용한다. 언어 메뉴는 EN / English, KR / 한국어로 표시하고, `/ko` 주소와 기존 영어 주소를 유지한다. 프로젝트 ID와 저장 데이터는 언어 전환으로 바뀌지 않는다. 사용자 콘텐츠, 외부 모델명 및 외부 패키지 설명은 원문을 유지한다.

전체 경로의 JavaScript gzip 합계는 694,726바이트로, 기존 616,000바이트 한도를 78,726바이트 초과했다. 첫 화면 전송량이 아니라 모든 청크의 합계다. 별도 SDK나 번역 모델은 브라우저에 추가하지 않았다. 용량 조사와 예산 결정은 [한국어 로캘 예산](architecture/KOREAN-LOCALE-BUDGET.md)에 기록한다.

검증: 4개 언어 키·자리표시자 일치, 타입 검사, 구조 검사, 프로덕션 빌드, EN→KR→새로고침→EN 브라우저 전환과 같은 프로젝트 유지. 실제 화면 검증 자료는 `research/evidence/provider-locales/`에 보관한다.
