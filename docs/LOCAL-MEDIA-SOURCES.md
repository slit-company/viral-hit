ima2 includes its own UI/server and native dependencies, kept outside the studio. The [optional bridge](../extensions/ima2/README.md) uses explicit provider/model selection, read-only recovery and project image pins. No upstream source or UI is copied into this adapter. Aside confirmed the pinned 3.26.3 release on 2026-10-20. Its `lib/imageBackgroundParam.ts`/`lib/alphaDecode.ts` inspect actual alpha pixels: a PNG header alone cannot establish transparency. The bridge does not yet implement alpha-pixel verification, masks, branch UI, video or provider/model discovery. Existing ComfyUI/Router verification remains separate.

These integrations provide authoring/rendering and generation transport; fixture results do not establish model-generation quality. General and specialized recipes can author different documents within the bridge bounds. Broader media support should extend verified project-asset bindings rather than accept arbitrary host paths.
