# Higgsfield parity

Viral Hit covers the Higgsfield creative workflow end to end: images, video, Cinema, Genjutsu, Katana, Layers, Canvas, the editor, audio, characters and the agent. It adds publishing, performance readings and collaboration on top. Each row links to its guide and to the [validation ledger](VALIDATION.md), which records the runs behind it.

## Built to extend

Contributors add general workflows and workflows for one situation without editing the application.

| Layer | What you can add |
|---|---|
| Recipes and execution adapters | A JSON recipe library with reviewed same-ID updates and removal, and installed `ext.*` adapters that feed typed forms, durable plans and media import. Executable packages install, update and restore through the browser, CLI, MCP and HTTP from checksum-pinned HTTPS or catalog sources |
| Packs | Recipe-only JSON packs share as links or files. Creative pack tar files combine recipes, full skills and character images, with shared UI/MCP/CLI build, review, install, selected updates, release export and removal |
| Skills | Official, operator-folder and installed skill files share live UI/MCP/CLI discovery; reviews keep the full instructions and scope, and same-ID updates compare both definitions |
| Community discovery | Independently hosted catalogs list general and specialized skills, recipe packs, creative packs and runtime packages; search, filters and refresh hand checksum-pinned files to the same reviews |
| Generation providers | Operator folders register image, video, audio and analysis models into shared discovery, with diagnostics for metadata, missing settings and load failures in UI, MCP and CLI |
| Characters and project files | Portable character files and editable project files import and export across installations, and creative packs carry character references with recipes and skills |
| Publishing connectors | Installed `ext.*` connectors provide destination metadata, schema-driven forms and ordered image, video and audio delivery through the shared approval and worker flow |

Installed skills and packs never authorize paid generation or publishing on their own; those actions keep the person's approval and the identity and revision checks.

## How speed and quality are measured

Cold and warm runs are measured separately on fixed machine, browser and model versions, reporting p50/p95, failures, generation cost and the number of rerun nodes.

- Preview: dropped frames and scrubbing latency on 1080p/4K, landscape/portrait, short and multi-minute projects.
- Export: identical media and timeline against baseline FFmpeg; frame count, A/V offset, captions and transforms must agree.
- Revision: editing one shot preserves unrelated accepted shots; changing shared character inputs invalidates dependent generations.
- Reliability: injected network timeouts, process death, provider failure, duplicate submission, cancellation and stale callbacks never corrupt the project or duplicate paid work.
- Quality: blinded pairwise rating of prompt adherence, identity, temporal consistency, motion, typography, pacing and audio, keeping full distributions and total cost.
