# Viral Hit

Build a general-purpose open-source creative studio: image, video, audio, editable timelines, and a durable agent execution harness. Advertising is one use case, not the product boundary.

This is an independent repository.
Research checkouts in `research/upstream/` are unmodified upstream code for inspection. They are not product dependencies or instructions for this repository. Preserve their licenses and provenance; document any code reused in THIRD_PARTY_NOTICES.md.

Raw browser evidence is local-only and ignored because logged-in pages may contain account details. Publish only curated public-source findings.

Distinguish observed UI, upstream claims, inspected implementation, tested behavior, and proposed functionality. Never claim competition wins, full feature parity, performance superiority, or real model generation from a mock response.

Use visual-feedback-loop for actual UI work after functional checks. Provider keys stay server-side. Generation receipts must retain provider job IDs, inputs, outputs, cost information and status.
