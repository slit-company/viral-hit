이 약관은 Viral Hit 소스 코드, 배포 버전, 저장소에 적용됩니다. Viral Hit을 사용하면 이 약관에 동의한 것으로 봅니다.

## 1. 오픈소스 소프트웨어

Viral Hit은 Apache License 2.0으로 배포됩니다. 코드를 사용, 복사, 수정, 배포할 권리는 해당 라이선스에 따릅니다. 이 약관과 라이선스가 충돌하면 라이선스가 우선합니다.

## 2. 설치 환경 관리

Viral Hit은 사용자가 관리하는 기기나 서버에서 실행됩니다. 설치 환경, 데이터베이스와 미디어 파일, 백업, 네트워크 공개 범위, 접근 권한은 사용자가 관리할 책임이 있습니다. 다른 사람에게 서비스를 제공하는 경우 사용자가 해당 배포 환경의 운영자가 되며, 이용자에게 별도의 이용약관과 개인정보 처리방침을 제공해야 합니다.

## 3. 연결한 서비스

Viral Hit은 사용자가 선택하고 설정한 Cloud API 엔드포인트, ComfyUI 서버, ima2 서버, YouTube, Instagram 등의 서비스에 연결할 수 있습니다. 각 서비스는 독립적으로 운영되며 자체 약관과 개인정보 처리방침이 적용됩니다. Viral Hit은 미디어 생성, 참고 영상 다운로드, 승인한 게시 등 해당 서비스가 필요한 작업을 실행할 때만 데이터를 전송합니다.

## 4. 인증 정보

연결에 사용하는 API 키, OAuth 연결, 저장소 인증 정보, 암호화 키를 안전하게 관리하세요. Viral Hit은 생성 서비스의 인증 정보를 서버에 암호화하여 저장합니다. 인증 정보가 노출된 것으로 의심되면 교체하세요.

## 5. 입력 자료와 생성 결과

사용하는 프롬프트, 미디어, 프로젝트 데이터에 대한 사용자의 권리는 그대로 유지됩니다. 사용자는 해당 자료를 사용하는 데 필요한 권리와 동의를 확보해야 합니다. 생성 결과는 부정확하거나 다른 결과와 유사할 수 있으므로 게시하거나 상업적으로 사용하기 전에 검토하세요.

## 6. 허용되는 사용

Viral Hit을 법률 위반이나 타인의 권리 침해에 사용해서는 안 됩니다. 동의 없이 타인의 얼굴, 목소리, 외모를 사용하거나, 타인을 속이는 사칭 콘텐츠, 동의 없는 사적 성적 콘텐츠, 미성년자가 등장하는 성적 콘텐츠를 만들어서는 안 됩니다. 악성코드 배포나 연결한 서비스의 안전장치, 과금, 사용량 제한을 우회하는 용도로도 사용할 수 없습니다.

## 7. 보증의 부인

Viral Hit은 어떠한 보증도 없이 있는 그대로 제공됩니다. 법률이 허용하는 최대 범위 내에서 기여자는 간접적·결과적 손해, 데이터 손실, 외부 서비스 장애, 인증 정보의 무단 사용, 입력 자료나 생성 결과에서 발생한 청구에 대해 책임을 지지 않습니다.

프로젝트가 발전함에 따라 이 약관이 변경될 수 있습니다. 위 날짜는 최신 버전을 나타냅니다. 문의나 신고는 [Viral Hit 저장소](https://github.com/slit-company/viral-hit/issues)에 남겨 주세요.
